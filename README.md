## 👋 Introduction

**Matrix Admin** is a free **Bootstrap 5 admin dashboard template** from [WrapPixel](https://wrappixel.com/). It's plain **HTML5, CSS3 (SCSS) and jQuery**, so you can use it as the front end of any back-end stack: PHP, Laravel, Django, Rails, Node.js or ASP.NET.

It includes two dashboards, charts, widgets, forms, tables, a calendar, chat, gallery, invoice and authentication pages. That's everything you need to start an admin panel, CRM, analytics dashboard or internal tool.

## 🔑 Features

- **Bootstrap 5** responsive grid and components
- **2 dashboard layouts** with Flot charts and Sparkline mini charts
- **Form basics and a multi-step form wizard**
- **Tables, grid, buttons and UI elements**
- **Apps:** calendar, chat, gallery and invoice
- **Font Awesome and Material Design icons**
- **Login, register and error pages** (403, 404, 405, 500)
- **SCSS source files** in `src/scss` for easy theming
- **Perfect Scrollbar** sidebar and waves click effect

## 💾 Getting started

No build step needed. Clone or download the repository and open `html/index.html` in your browser.

```bash
git clone https://github.com/wrappixel/matrix-admin-bt5.git
```

### 📁 Folder structure

```
matrix-admin-bt5/
├── assets/
│   ├── images/        # Logos, users, backgrounds
│   ├── libs/          # Bootstrap, jQuery, Flot, Perfect Scrollbar
│   └── extra-libs/    # Sparkline and other plugins
├── dist/
│   ├── css/           # Compiled style.min.css
│   └── js/            # Custom scripts, sidebar menu, page scripts
├── html/              # All template pages (start with index.html)
└── src/scss/          # SCSS source files
```
